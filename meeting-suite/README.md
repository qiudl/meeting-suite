# 会议套件（@zhangguitao666/meeting-suite）

一个 npm 伞包，安装后同时得到两个插件：

- **dsh-plugin-meeting-minutes**：实时录音转文字、腾讯会议纪要导入、AI 可视化纪要、待办确认、会议结束自动入库。
- **dsh-plugin-task-calendar**：日历任务、开始/截止提醒、月历与甘特图。

## 安装

Harness 的 **Plugins → Add plugin** 里输入：

```
@zhangguitao666/meeting-suite
```

或在 Agent 里让 `plugin_manager install_bundle` 安装这个包。安装后 ⌘R 刷新页面，左侧出现「会议纪要」和「任务日历」两个入口。

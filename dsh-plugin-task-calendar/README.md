# 任务日历（dsh-plugin-task-calendar）

把**会议纪要 / 聊天里确认的事项**变成日历上的任务，并在任务开始、临近截止、逾期时提醒你。

- 左侧栏出现「任务日历」图标 → 打开整月日历面板。
- 我在对话里读你的纪要、抽出任务，然后调用插件工具写入日历（你也可以在面板里手动新建/编辑）。
- 提醒三条路一起走：**日历面板内的徽标与横幅**、**右下角应用内弹窗**、**系统通知**（macOS 通知中心）。
- 任务状态实时显示：`今天开始` / `还剩 N 天` / `逾期 N 天` / `进行中` / `已完成`。

---

## 一、从会议纪要生成任务

把纪要直接贴给我（或在对话里说「把刚才那份纪要变成待办」），我会读完后调用：

```
calendar_add_tasks({
  tasks: [
    { title: "输出 Q4 预算初稿", due: "2026-10-15 18:00", owner: "张三", notes: "含三张明细表" },
    { title: "和供应商确认报价", start: "2026-10-12 14:00", due: "2026-10-12 16:00", priority: "high" }
  ],
  source: { kind: "minutes", title: "Q4 启动会", date: "2026-10-09" }
})
```

要点：

- **不是我让插件去理解纪要，而是我先读懂，再结构化写入** —— 抽取质量取决于对纪要的理解，工具只负责落库和排期。
- 相对时间要换算成具体日期：`下周三` → `2026-10-14`。工具本身也认 `明天 09:30`、`周五 17:00`、`2026-10-12`、`2026-10-12 18:00`。
- `start` 决定「任务开始提醒」，`due` 决定「还剩 N 天 / 逾期」提醒；只给日期则是全天任务。
- 同一场会议的任务用同一个 `source`，日历卡片上会显示来源，便于回溯。

### Agent 可用的五个工具

| 工具 | 作用 |
| :-- | :-- |
| `calendar_add_tasks` | 批量创建任务（会议纪要入口） |
| `calendar_list_tasks` | 查看任务：`range` = all / today / week / week-calendar / month / overdue / upcoming，可按状态与关键词过滤，返回每条任务的剩余或逾期天数 |
| `calendar_update_task` | 改时间、改标题、标记完成/进行中、补负责人备注标签 |
| `calendar_delete_task` | 删除任务 |
| `calendar_reminder_config` | 查看或调整提醒规则 |

## 二、日历面板

- **月视图**：一整个月是一块**无缝的网格**（格子之间用共用细线分隔，没有间隙，外框圆角），有任务的格子显示彩色块（**红=逾期，橙=今天/临近，蓝=未来，绿=已完成**）。
- **格子里的色块与甘特条同款**：淡色底 + **实色进度层**（已过时间占比，用同一套配色与圆角），只是**不在块内显示文字**；跨天横带同样带进度层，能看出整段跨度走了多少。
- **鼠标悬浮在色块或横带上弹出浮窗**，显示任务名、状态、开始/截止时间、时长、负责人、优先级、来源、标签、备注摘要和剩余/逾期徽标 —— 与甘特图共用同一个浮窗；单击色块直接编辑。右侧当日清单仍然逐条列出文字详情。
- **行高按内容自算，该显示的都显示**：每周行会按自己的内容（几层跨天横带 + 几个任务）自动长高，所以**两层横带加当天的任务能同时看见**；内容实在过多的格子才收成 `+N`。整月超出窗口时网格整体滚动，而不是把内容藏起来（也不会把字切一半）。
- **任务不会凭空消失**：无论窗口多矮，跨天横带和当天任务都保证各自可见；万一某行真放不下额外横带，会显示 `+N 跨天` 标记而不是静默丢弃。
- **跨天任务是连着的一条**：跨越多天的任务不再只出现在开始那天，而是横跨它覆盖的每一天画成一条连续横带（左侧圆角=真正开始、右侧圆角=真正结束；跨周时那一边是平的，下一周接着画，看上去就是一条）。同一周里重叠的跨天任务会自动分层，最多 3 层。
- **右侧当日清单**同样按覆盖的每一天列出跨天任务，并标注 `跨天 2/3`，避免以为是重复项。
- **右侧当日清单**：状态徽标（还剩/逾期）、开始与截止时间、负责人、标签、来源、备注；一键「完成 / 编辑 / 删除」。
- **未排期**：没写时间的任务单独列在下面，不触发到期提醒。
- **顶部统计**：共 N 项 · 逾期 N · 今天 N · 进行中 N · 已完成 N；侧栏图标上还有逾期+今天的角标。
  - **进行中**按时间算，不看你手动改没改状态：**已开始、未逾期、未完成**就计入（例如 10-20 看一个 10-19→10-21 的任务，它算进行中）。
  - **今天** = 截止时间落在今天（且未完成）。
- **提醒横幅**：面板顶部列出当前待确认的提醒，点「知道了」即确认。
- 双击日历格子 = 在那天新建任务；「提醒设置」里可改规则并开启系统通知。

## 三、甘特图 · 任务进度（月历下方）

月历下面就是甘特图，一条任务一行，横条表示它的时间跨度。

- **实色 = 已经过去的时间**，浅色 = 还没到的时间。一眼看出某件事"过了多少、还剩多少"。
- **竖线 = 今天**（打开面板时会自动滚到让今天居中）。
- **横条颜色**跟日历一致：**绿=已完成、红=逾期**、橙=今天/临近、蓝=往后（已完成的名字带删除线，色块是实心绿）。
- **只填了截止时间（带具体时间）、没填开始时间的任务**在截止时刻画一个**实心菱形◆**（不编造开始时间），颜色同样跟随状态：已完成绿、逾期红；鼠标悬停能看到确切时刻。只写日期不写时间的任务则是**整天的条**（斜纹底色），不会被当成一个点。
- **范围切换**：**一天** / 本周 / 两周（默认）/ 本月 / 全部。跨度大的任务用「全部」看整体，日常用「两周」。
- **「一天」视图**：时间轴按小时刻度展开，任务条**精确到分钟**（例如 14:30–16:00 就是 1.5 小时宽），竖线是**现在**（精确到分钟）；左上角 `‹ ›` 切换上一天/下一天，并跟着月历里选中的那天走。「全天」任务（只写了日期没写时间）在一天视图里铺满整天，跨夜的任务会被裁到当天边缘并在标签上标 `→`。
- **横条够宽时在条内显示文字**（粗视图显示剩余/逾期天数，一天视图显示时间段），条太窄就省略以免看不清；鼠标悬浮在横条上还会弹出**浮窗**，显示：状态、开始、截止、时长、负责人、优先级、来源、标签、备注摘要，以及剩余/逾期徽标；单击横条直接打开编辑弹窗。
- **左列任务名**固定在左侧，横向滚动时不会跑掉；点任务名或横条都能打开编辑弹窗。
- 上下的**分隔条可以拖动**，自己决定月历和甘特图各占多高；右上角「收起」可以整个折叠甘特图。
- 没排期的任务不画进来（它们本来就没有时间轴位置），在右侧「未排期」清单里。

## 四、提醒规则（默认值）

| 时机 | 说明 |
| :-- | :-- |
| 到期前 3 天 / 1 天 / 2 小时 | 面板徽标 + 弹窗（可在「提醒设置」里改） |
| 到截止时刻 | 「已到截止时间」 |
| 逾期后每天 09:00 | 「已逾期」，直到任务完成 |
| 开始前 30 分钟 | 「N 分钟后开始」（仅对带具体时间的 `start`） |

同一任务只会弹出**最新一条**未确认的提醒；确认之后，比它更早的历史提醒一并作废，不会积压刷屏。

## 五、安装 / 卸载

安装（推荐在应用内安装，profile 会热加载新 bundle）：

```
plugin_manager install_bundle  /Users/zgt/Documents/deepseek-harness/default-workspace/dsh-task-calendar
```

装好后**刷新一次网页**（新加入的浏览器端 bundle 只在页面重新加载时进入启动清单）：macOS `⌘R`。
之后左侧栏就会出现日历图标。

- 停用但保留：`plugin_manager set_bundle dsh-plugin-task-calendar enabled=false`
- 彻底卸载：`plugin_manager remove_bundle dsh-plugin-task-calendar`
- 命令行方式（需先完全退出桌面应用，因为它锁另一个文件）：
  `/Applications/DeepSeek\ Harness.app/Contents/Resources/runtime/cli/bin/dsh plugin --profile desktop add /Users/zgt/Documents/deepseek-harness/default-workspace/dsh-task-calendar`

**升级/改代码后**：已安装包的热更新不会重新加载 JS 模块，需要重启一次桌面应用（或先 remove 再 install 并刷新页面）。

## 六、数据与实现

- 数据文件：`$DSH_HOME/storages/task-calendar.json`（默认 `~/.dsh/storages/task-calendar.json`）；改名前的 `calendar-tasks.json` 会在首次启动时自动迁移过来，任务不丢。写入一次原子落盘（临时文件 + rename），损坏时备份为 `.corrupt-<时间戳>` 并空库启动。
- 宿主侧（`lib/index.js`）：任务仓库 + 五个 Agent 工具 + `ctx.webServer` 上的本机 JSON 接口 `/dsh-task-calendar/*`（仅允许回环地址访问）。
- 浏览器侧（`lib/client.js`，手写 bundle，无构建步骤）：注册 `sidebar.panellist`（任务日历图标）、`main`（面板，key=`calendar`）、`shell.overlay`（提醒弹窗），并每 30 秒轮询宿主状态。
- 卸载插件后，数据文件与任务不会自动删除，重装即可继续使用。

# 会议纪要（dsh-plugin-meeting-minutes）

把**一场会**变成一份**能看、能带走、能落到日历上**的会议纪要：

- **实时录音转文字**：面板里直接录音，每约 5 秒滚动识别一段，6–10 秒后就能看到文字；录音在后台运行，关掉弹窗、切到其他面板都不中断。也可导入本机录音/视频文件（wav/mp3/m4a/mp4/aac），长音频自动切片。
- **自动入库**：腾讯会议本地录制结束后自动发现、转写、存成「待整理」会议；也可以把导出的纪要/录音丢进监控目录，自动入库，不用每次手动导入。
- **腾讯会议纪要文本**：把客户端里的「智能纪要 / 转写」复制粘贴进来，或导入 `.txt/.md/.json` 导出文件；不用给插件账号密码。
- **AI 总结**：调用当前默认模型，生成一句话结论、关键要点、会议决策、风险/待确认、分节纪要，并把行动项抽成待办。
- **可视化会议纪要文档**：面板里就是一个排版好的纪要页（封面信息、结论高亮、要点卡片、决策清单、风险提示、分节正文、待办表），还能一键导出**独立 HTML**（可直接打开/打印/分享）或 Markdown。
- **待办写入任务日历**：勾选确认后的待办，写入「任务日历」插件（已安装时），按截止/开始时间提醒；再次生成纪要不会重复写入已确认的待办。

## 一、面板怎么用

左侧栏「会议纪要」图标 → 打开面板。左边是会议列表，右边是选中会议的纪要文档。

| 场景 | 操作 |
| :-- | :-- |
| 现场开会、手机/电脑录音 | 顶部「录音」→ 标题留空也行 → 「开始实时转写」→ 边说边出字；可点「后台录音」关掉弹窗继续用软件，底部录音条随时停止 |
| 已有录音文件 | 顶部「导入」→ 选音频/视频文件 → 自动转写并建会议 |
| 腾讯会议纪要 | 顶部「导入」→ 粘贴文本（或选 `.txt/.md/.json`）→ 建会议 |
| 生成/重生成纪要 | 右上「AI 生成纪要」，几十秒后右侧文档更新 |
| 变成任务 | 在待办表里勾选 → 「写入任务日历（N）」；已写入的显示日历任务 id |
| 带走文档 | 「导出 HTML」或「导出 Markdown」；文件写到 `~/.dsh/meeting-minutes/exports/` |
| 改纪要文字 | 直接编辑待办的负责人/截止/优先级/备注后写入；标题、日期、参会人可在会议头部编辑 |

### 自动入库（腾讯会议结束后自动留存）

- **腾讯会议本地录制**：插件只读腾讯会议 macOS 客户端的 `local_record_data` 表，发现「录制完成 + 文件还在本机」的记录后，自动用本机 SenseVoice 转写并建会议（标题用腾讯会议的录制标题，找不到就用「录音纪要 时间」），标记为自动入库、等你有空整理。
- **监控目录**：在「自动入库」设置里添加任意目录（一行一个），新出现的 `m4a/mp4/wav/mp3/aac/webm/mov` 会自动转写；`txt/md/docx` 会直接抽文本入库；腾讯会议导出的纪要文件放进去即可。
- 扫描每 30 秒一次，默认开启、可随时关闭；同一来源不会重复导入，失败最多重试 3 次；面板会提示「已自动导入：xxx（待整理）」。
- **限制**：腾讯会议「云端智能纪要」没有个人版 API，插件只能拿到本机录制或你导出的文件；如果只用云录制/云转写，需要在腾讯会议里导出，或使用企业版开放平台凭证接 API。

### 标题：先默认，后修改，AI 自动命名

- 录音/新建会议都可以**不填标题**：自动用「录音纪要 2026-10-21 17:30」这类占位名，先开始再说，不用在会议开始时停下来想名字。
- 会后随时可以改：会议文档右上「编辑会议信息」里改标题、日期、参会人。
- 让 AI 生成纪要时，如果标题还是自动占位名，模型会顺便起一个真正的会议名（例如「Q4目标预算与上线排期」）并自动替换；**你自己写过的标题不会被改**。接口里传 `autoTitle: false` 可以关闭自动改名。
- 这样「会议很急」和「纪要整理拖到最后」不再冲突：先录/先导入，命名和整理都交给后续 AI 步骤。

### 实时转写与后台录音

- 录音使用 Web Audio 采集 PCM，**每约 5 秒**编码成 16kHz 单声道 WAV 发给本机 SenseVoice，识别结果滚动追加到会议。首段文字通常在开口后 **6–10 秒**出现。
- 录音状态、音频节点与发送队列都在页面模块作用域，**关闭录音弹窗、切换到对话或其他面板、最小化参数面板都不会停止录音**；底部常驻「录音中」浮动条显示计时、已转写字数、最近一句，并提供「停止」「打开纪要」。
- 停止时会先发完最后一段再收尾，自动刷新会议与列表；期间可以继续操作软件（只有关闭/刷新整个页面会中断）。
- 本机识别服务只提供整段识别，所以这里是「短段滚动识别」而不是逐字流式；切片边界偶尔会把一句话切成两段（识别文本仍完整保留）。如果需要真正逐字上屏，可以后续接云厂商流式 ASR。

### 腾讯会议的纪要文本从哪来

腾讯会议个人版没有公开的「读取我的纪要」接口，本插件走**文本/录音导入**，三条路都行：

1. **会后**：腾讯会议客户端 →「历史会议 / 会议详情」→ 智能纪要或转写记录 → 全选复制 → 粘贴到「导入」。
2. **会中录制**：开启了云录制/本地录制时，会后可下载录音或转写文本；音频文件直接拖进「导入」即可转写。
3. **本地录制文件**：macOS 上通常在 `~/Documents/TencentMeeting/` 下（按版本可能不同），选 `.m4a/.mp4` 导入即可。

> 如果你有企业版开放平台凭证、希望插件直接拉取纪要，需要在插件里接腾讯会议 OpenAPI；当前版本刻意不内置账号体系，避免把密钥写进配置。

### 语音识别说明

- 默认使用 Harness 内置的**本机 SenseVoice**（`@deepseek-ai/dsh-experimental-voice-input-bundle` 提供），音频不离开本机。
- **第一次转写**会下载识别模型（本机实测约 242MB，面板顶部会显示「准备中/下载进度」）；网络受限时下载可能失败，此时面板会提示改用文本导入。
- 识别要求 16kHz 单声道 PCM16 WAV；面板在浏览器里完成解码/重采样/切片（≤90 秒一片），不依赖 ffmpeg。
- 从本机文件转写（Agent 工具）时，非 canonical 音频会用 macOS 自带 `afconvert` 转码。

## 二、Agent 也能用（对话里说就行）

装好后我在对话里也能直接操作同一套数据：

| 工具 | 作用 |
| :-- | :-- |
| `meeting_list` | 列出会议（按日期倒序，可搜索） |
| `meeting_get` | 读一场会议的完整纪要/待办/原文 |
| `meeting_create` | 把一段会议文本存进纪要库 |
| `meeting_transcribe` | 把本机录音/视频文件转文字并建会议 |
| `meeting_summarize` | 用默认模型生成结构化纪要 |
| `meeting_push_todos` | 把确认后的待办写入任务日历 |
| `meeting_export` | 导出 HTML/Markdown 到文件 |

例子：「把 `~/Documents/TencentMeeting/1021.m4a` 转成纪要，待办同步到日历」。

## 三、安装 / 卸载

在应用内安装（profile 会热加载新 bundle）：

```
plugin_manager install_bundle  /Users/zgt/Documents/deepseek-harness/default-workspace/dsh-meeting-minutes
```

装好后**刷新一次网页**（新浏览器端 bundle 只在页面重新加载时进入启动清单），左侧栏出现「会议纪要」图标。

- 停用但保留：`plugin_manager set_bundle dsh-plugin-meeting-minutes enabled=false`
- 彻底卸载：`plugin_manager remove_bundle dsh-plugin-meeting-minutes`
- 依赖：宿主自带的 `tools`、`webServer` 服务；`speechToText`（语音识别）与 `llm`（总结）为可选服务，缺失时对应按钮会给出中文提示。

## 四、数据与接口

- 会议数据：`$DSH_HOME/storages/meeting-minutes.json`（原子落盘；损坏时备份为 `.corrupt-<时间戳>` 并以空库启动）。自动入库的开关、监控目录与已导入来源也记录在这里。
- 导出文件：`$DSH_HOME/meeting-minutes/exports/`。
- 宿主 HTTP：`/dsh-meeting/*`（仅回环地址），完整契约见 `CONTRACT.md`；浏览器面板通过它读写，不依赖生成式 Remote 通道。
- 写入日历走任务日历插件的公开接口 `/dsh-task-calendar/tasks`，两个插件可独立安装/卸载；未安装任务日历时会明确提示。

## 六、已知限制

- 腾讯会议没有个人版开放接口：能自动拿到的是**本机录制**（或你导出到监控目录的文件）；云端智能纪要需导出或企业 API。
- 本机 SenseVoice 模型首次使用需联网下载；下载失败时只能走文本导入（或改用其它机器）。
- 实时转写按 5 秒切片滚动识别，切片边界可能切断一句话（文本不丢）；真正逐字流式需要云 ASR，暂未接入。
- 录音时长上限取决于模型与内存，超长会议建议分段导入；单次总结会把超长文本压到 14 万字以内（保留头尾）。
- 「写入任务日历」只是创建任务，不会反向删除日历里已建的任务；改时间请在任务日历面板里改。
